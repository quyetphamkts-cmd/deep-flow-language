Chạy nền

Hiện câu đang đọc trên màn hình khoá
App vẫn phát khi bạn thoát ra màn hình chính hoặc tắt màn hình (điều khiển ở thanh thông báo và màn hình khoá, nút ⏮ ⏭ chuyển câu). Để Android không tắt app:
1. Mở bằng Chrome, không đóng tab Deep Flow (chỉ bấm nút Home để thoát ra).
2. Cài đặt điện thoại → Ứng dụng → Chrome → Pin → chọn Không hạn chế.
3. Máy Xiaomi/Oppo/Vivo/Samsung: bật thêm Tự khởi chạy, và khoá Chrome trong danh sách ứng dụng gần đây (vuốt xuống trên thẻ Chrome hoặc bấm biểu tượng ổ khoá).
4. Nếu thấy mất tiếng khi tắt màn hình lúc đang bật EQ, hãy thử tắt EQ.

Google Drive

Để thêm bài từ link Google Drive, app cần một API key (miễn phí, làm 1 lần):
1. Vào console.cloud.google.com, đăng nhập Gmail, tạo một Project mới.
2. Mục APIs & Services → Library, tìm Google Drive API → bấm Enable.
3. Mục Credentials → Create credentials → API key, copy key và dán vào ô trên.
4. Ở Drive, chia sẻ file/thư mục ở chế độ "Bất kỳ ai có đường liên kết".
Lưu ý: nếu giới hạn key thì chỉ giới hạn theo API (Google Drive API), đừng giới hạn theo website.

Phụ đề

🔗 Thêm từ link

Dán mỗi link một dòng. Hỗ trợ:
• Link thư mục Google Drive: nạp cả thư mục (kể cả thư mục con), tự ghép âm thanh với tài liệu cùng tên
• Link file Google Drive, Google Docs
• Link tải trực tiếp khác (nếu trang đó cho phép)
Âm thanh trên Drive được nghe trực tiếp (☁, không chiếm bộ nhớ máy); muốn nghe offline thì bấm ⋯ → Tải về máy cho từng bài hoặc cả album.
