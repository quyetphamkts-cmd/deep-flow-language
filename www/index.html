Tự phát khi kết nối tai nghe
Hoạt động khi Deep Flow đang mở hoặc đang chạy nền trong Chrome. Khi rút tai nghe, Chrome tự dừng phát. Nút Play trên tai nghe Bluetooth luôn điều khiển được Deep Flow. Muốn app tự mở khi đã tắt hẳn thì cần bản APK.
App vẫn phát khi bạn thoát ra màn hình chính hoặc tắt màn hình (điều khiển ở thanh thông báo và màn hình khoá, nút ⏮ ⏭ chuyển câu). Để Android không tắt app:
1. Mở bằng Chrome, không đóng tab Deep Flow (chỉ bấm nút Home để thoát ra).
2. Cài đặt điện thoại → Ứng dụng → Chrome → Pin → chọn Không hạn chế.
3. Máy Xiaomi/Oppo/Vivo/Samsung: bật thêm Tự khởi chạy, và khoá Chrome trong danh sách ứng dụng gần đây (vuốt xuống trên thẻ Chrome hoặc bấm biểu tượng ổ khoá).
4. Nếu thấy mất tiếng khi tắt màn hình lúc đang bật EQ, hãy thử tắt EQ.

🤖 API AI — nghe, chép lời, dịch

Mỗi người dùng tự tạo key của mình. Gemini miễn phí (tài khoản Google); Claude và ChatGPT trả phí theo lượt dùng. App tự chọn AI phù hợp nhất cho từng việc trong số các AI đã thêm. Key chỉ lưu trong máy này và trong tài khoản Google bạn đăng nhập ở mục Tài khoản & đồng bộ — máy khác đăng nhập cùng tài khoản sẽ tự có key, đăng xuất thì key được gỡ khỏi máy. Key không nằm trong file sao lưu.
Gemini API keyTạo phụ đề bằng Gemini, dịch bằng Gemini, vẽ hình minh hoạ từ vựng
Cách lấy Gemini API key
  1. Mở aistudio.google.com/apikey và đăng nhập tài khoản Google.
  2. Lần đầu: đồng ý điều khoản sử dụng.
  3. Bấm Create API key (Tạo khoá API). Nếu được hỏi project, chọn project có sẵn hoặc để Google tự tạo.
  4. Bấm biểu tượng copy cạnh key vừa tạo (key bắt đầu bằng AIza, dài 39 ký tự).
  5. Quay lại app, bấm Nhập key → 📋 Dán → OK.
Gói miễn phí có giới hạn số lần gọi mỗi phút/ngày, đủ cho học cá nhân. Không chia sẻ key cho người khác.
Claude API key (Anthropic)Dịch song ngữ, giải nghĩa từ, ví dụ — tự nhiên nhất. Trả phí theo lượt dùng
Cách lấy Claude API key
  1. Mở console.anthropic.com, đăng ký / đăng nhập.
  2. Vào Plans & Billing → nạp tiền (tối thiểu khoảng 5 USD; dùng cho học cá nhân rất lâu mới hết).
  3. Vào API Keys → Create Key, đặt tên (ví dụ Deep Flow) → copy key (bắt đầu bằng sk-ant-). Key chỉ hiện 1 lần.
  4. Quay lại app: Nhập key → 📋 Dán → OK.
ChatGPT API key (OpenAI)Tạo phụ đề bằng Whisper (mốc thời gian chính xác nhất), dịch, giải nghĩa. Trả phí theo lượt dùng
Cách lấy ChatGPT API key
  1. Mở platform.openai.com, đăng nhập (dùng được tài khoản ChatGPT). Lưu ý: gói ChatGPT Plus không bao gồm API.
  2. Vào Settings → Billing → nạp tiền (tối thiểu 5 USD).
  3. Vào API keys → Create new secret key → copy key (bắt đầu bằng sk-). Key chỉ hiện 1 lần.
  4. Quay lại app: Nhập key → 📋 Dán → OK.
Chi phí tham khảo: tạo phụ đề ~0,006 USD/phút âm thanh (bài 5 phút ≈ 750 đồng); dịch, tra từ chỉ vài đồng mỗi lần.
Ưu tiên khi chọn AIHiệu quả nhất: Claude dịch/giải nghĩa, ChatGPT Whisper tạo phụ đề, Gemini dự phòng. Tiết kiệm: dùng Gemini miễn phí trước, AI trả phí chỉ khi Gemini hết lượt. Hết lượt tất cả → Google Dịch / Whisper trên máy.

🔑 API lưu trữ — Google Drive

Google Drive API keyThêm bài từ link hoặc thư mục Google Drive, nghe trực tiếp từ Drive
Cách lấy Google Drive API key
  1. Mở console.cloud.google.com, đăng nhập tài khoản Google, tạo một Project mới (đặt tên tuỳ ý, ví dụ Deep Flow) → Create.
  2. Mở trang Google Drive API (chọn đúng project vừa tạo ở góc trên) → bấm Enable (Bật).
  3. Mở Credentials → Create credentials → API key → copy key.
  4. (Nên làm) Bấm vào key → mục API restrictions chọn Restrict key → Google Drive API → Save. Đừng giới hạn theo website.
  5. Quay lại app, bấm Nhập key → 📋 Dán → OK.
Ở Google Drive, file/thư mục muốn nghe phải chia sẻ ở chế độ “Bất kỳ ai có đường liên kết”.
